# 🌍 openworld · 分镜出片工厂

**分镜脚本 → AI 建造 → 自动出片**，一条命令产出全套分镜视频。

## 快速开始

```
双击 启动.bat        → 打开 http://127.0.0.1:8500
左边输入分镜脚本      → 点 🎬 开拍
右边看进度和成片      → 视频/图片自动落入 output/<任务id>/
```

## 分镜脚本语法

```
# 这是注释
场景 中世纪村庄              ← 引用素材库已存场景（自动重建+重拍）
建造 城堡@65,90 房屋@76,88   ← 建造指令（坐标可省略→自动找陆地）
分镜:
远景                        ← 关键词自动映射机位
正门
环绕 8秒                    ← 视频：360°环绕+推近+下降
推近 5秒                    ← 视频：直线推镜
俯瞰  街道  庭院  塔  特写    ← 其他静帧机位
```

建造行坐标省略时（如 `建造 城堡 房屋 树`），自动寻找陆地按网格展开。

## 素材库（assets/，持续累计）

| 目录 | 内容 | 复用方式 |
|------|------|----------|
| `blueprints/` | 建筑蓝图元数据（城堡/房屋/望塔/石桥/树） | 脚本 `建造 城堡` 直接引用 |
| `scenes/` | **场景存档**：建筑布局+分镜套餐（每次任务自动存） | 脚本 `场景 xxx` 一键复现 |
| `shots/` | 机位预设（标准六机位等） | 脚本分镜行引用 |

## 架构

```
server.js          控制台服务器 + 渲染管线（零依赖）
lib/engine.js      CDP 引擎：headless Chrome 控制体素世界
lib/shots.js       分镜脚本解析器（自然语言→机位序列）
index.html         控制台 UI（脚本输入/进度/视频墙/素材库）
output/<jobId>/    产出（PNG 静帧 + WebM 视频）
```

依赖：Node 22+（内置 WebSocket）、Chrome、Cellcraft（`../voxel-projects/minecraft-web`，服务器自动拉起 :8200）。无需 ffmpeg——视频由页面内 MediaRecorder 直接录 WebM。

## 视频原理

游戏 canvas `captureStream(30)` → 页面内 `MediaRecorder`(VP9) → base64 分块经 CDP 回传 → 落盘 .webm。运镜通过驱动玩家坐标+视角实现（相机被游戏接管，必须移动玩家本体）。

## 已知铁律（踩坑沉淀）

1. 地面探测只认自然地块（grass/dirt/stone/sand/bedrock/snow），**树冠会污染高度导致建筑悬浮**
2. 等待就绪必须用布尔表达式（`typeof X` 字符串是 truthy 陷阱）
3. 方块 ID 必须合法，`addBlock` 无效 ID 静默失败
4. 玩家传送后等 `isOnGround` 再瞄准（悬空机位除外）
5. 静帧机位全线悬空定点拍（无人机视角），落地仰拍会因地形产生悬浮错觉
